
# Spam Email Detection Using SVM

## Project Overview
A machine learning application that classifies email text
as spam or legitimate using TF-IDF and a linear Support
Vector Machine (SVM).

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Linear SVM
- Streamlit

## Features
- Email text classification
- Spam and legitimate email predictions
- Model performance dashboard
- Confusion matrix
- Prediction history

## Dataset
Kaggle Spam Mails Dataset:
https://www.kaggle.com/datasets/venky73/spam-mails-dataset

## Run Locally
1. Install the required packages:
   pip install -r requirements.txt

2. Train the model:
   python train_model.py

3. Start the application:
   streamlit run app.py
